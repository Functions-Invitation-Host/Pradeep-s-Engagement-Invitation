# Pradeep & Shilpa | Engagement Invitation

Plain HTML, CSS and JavaScript. No install, no build step. Free on GitHub Pages.

Preview on your computer: double-click `index.html`.

## Publish for free (about 10 minutes)

1. **Account:** sign up or log in at https://github.com.
2. **New repository:** click **+** (top right) > **New repository**. Name it `pradeep-shilpa-engagement` (any name works). Choose **Public**. Click **Create repository**.
3. **Upload:** unzip this folder. On the new repository page click **uploading an existing file**. Open the unzipped folder, select **everything inside it** (including the hidden `.github` folder and `.nojekyll`), and drag it into the browser. Click **Commit changes**.
   - Mac: press Cmd+Shift+. to show hidden files. Windows: View > Show > Hidden items.
   - Check the repository shows `.github/workflows/deploy.yml`. If it is missing: **Add file > Create new file**, type `.github/workflows/deploy.yml` as the name, paste that file's contents, commit.
   - Easier alternative: install GitHub Desktop, **File > Add local repository** (this folder), **Commit to main**, **Publish repository** (untick "Keep this code private").
4. **Turn on Pages:** repository **Settings > Pages > Build and deployment > Source: GitHub Actions**.
5. **Wait:** open the **Actions** tab. A green tick (1 to 2 minutes) means it is live. If it failed because Pages was not yet enabled, open the run and click **Re-run all jobs**.
6. **Your link:** `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/` (also shown in Settings > Pages). Open it on your phone, then share on WhatsApp.

The share-preview links in `index.html` are filled in automatically when GitHub deploys; you don't need to edit them. WhatsApp caches previews: if the photo doesn't show, send the link with `?v=2` at the end.

## Music
Add a licensed instrumental named `background-music.mp3` into the `assets` folder (upload it on GitHub: open `assets` > **Add file > Upload files**). Guests tap "Open Invitation" to start it. Without the file the player does nothing.

## Update later
Open a file on GitHub > pencil icon > edit > **Commit changes**. It redeploys automatically in about a minute.

## Checklist
Both photos show; countdown runs; both Get Directions buttons open Google Maps; no sideways scrolling on a phone; WhatsApp preview appears.
